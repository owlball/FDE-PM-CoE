Legal Agreements

Four agreements cover the FDE lifecycle. You are not responsible for getting these signed — but you need to know which ones must be in place before each phase starts, and flag it as a blocker if they aren't.

FBA is a mandatory intake gate. No FDE activity can start without a signed FBA. Verify it is in scope before W1. The FTEA should be sent in W0 — track it as an open item until signed, and do not allow system access until it is back.

Delivery limits — 90 days / 300 PD

FDE delivery is free of charge. Two cumulative limits apply to the execution phase only — Discovery does not count:

  • 90 business days — maximum duration of the execution phase
  • 300 Person Days (PD) — maximum total SAP engineering effort

Whichever is reached first caps the engagement. These are scope constraints to keep in mind when planning — flag early if an engagement is trending toward either limit.
